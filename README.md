# Survey Map Dashboard (조사 위치 표시 대시보드)

이 프로젝트는 엑셀 데이터를 파싱하여 카카오 지도 기반의 웹 대시보드로 시각화하는 프로젝트입니다.
향후 유사한 지도 기반 데이터 시각화 프로젝트를 진행할 때 재사용하기 위해 기술적 노하우와 문제 해결 사례를 정리해 둡니다.

## 💡 핵심 기술 스택
- **Frontend**: React, Vite, TailwindCSS, `react-kakao-maps-sdk`, `lucide-react`
- **Backend**: Node.js, Express, `xlsx` (엑셀 파싱)
- **Database**: Supabase (상태 저장)
- **Deployment**: Onrender (무료 클라우드 호스팅)

---

## 🛠️ 주요 문제 해결 및 베스트 프랙티스 (Troubleshooting)

### 1. 카카오 지도 SDK 연동 및 오버레이 이벤트 버그 해결
- **문제**: 카카오 지도의 `<CustomOverlayMap>` 안에 있는 버튼을 클릭했을 때 이벤트가 무시되고 팝업이 닫히는 현상 발생.
- **해결**: 마커 핀과 팝업 창을 띄우는 `<CustomOverlayMap>` 컴포넌트에 **반드시 `clickable={true}` 속성을 부여**해야 오버레이 내부의 HTML 마우스 이벤트(클릭 등)를 지도가 가로채지 않습니다.
- **도메인 설정**: 카카오맵을 배포 환경에서 띄우려면 카카오 개발자 콘솔의 **[플랫폼] -> [Web]** 에 `http://localhost:3001`, 배포 도메인 등을 필수적으로 등록해야 `401 Unauthorized` 에러를 막을 수 있습니다.

### 2. 긴 텍스트 UI 오버플로우 (박스 이탈) 방지
- **문제**: 엑셀 데이터의 문자열(위치, 용량 등)이 너무 길어 띄어쓰기가 없는 경우, 팝업 창의 너비를 무시하고 텍스트가 바깥으로 삐져나가는 현상.
- **해결**: Tailwind CSS의 `break-words whitespace-normal` 클래스를 긴 텍스트가 들어가는 부모 `<div>`에 일괄 적용하여 무조건 줄바꿈 처리가 되도록 강제.

### 3. 모바일 친화적 (Responsive) UI 설계
- **문제**: PC 환경에 맞춰진 커다란 '상태 현황 모달' 창이나 여러 개의 상단바 버튼들이 모바일 화면에서는 지도를 크게 가리거나 화면 밖으로 밀려나는 문제.
- **해결**:
  1. 공간을 많이 차지하는 제목 텍스트 최소화 (아이콘화).
  2. 필터 기능(Select 박스)과 현황 위젯을 **하나의 버튼 토글형 팝업(Dropdown)** 으로 통합.
  3. 우측 상단의 `Filter` 아이콘 클릭 시만 부드럽게 창이 열리게(`animate-in fade-in zoom-in`) 처리하여 모바일에서의 쾌적한 맵 탐색 시야 확보.

### 4. 서버 로딩 최적화 및 상태 유지 (State Persistence)
- **문제**: 수천 줄의 엑셀을 매번 파싱하고, 무거운 Supabase 조회 쿼리가 반복되면 대시보드 로딩이 느려짐. Onrender 무료 서버 재시작 시 연결이 끊기는 현상.
- **해결**: 
  - 백엔드(`server.js`)에 전역 메모리 캐시 변수(`globalCachedData`)를 도입해, 서버가 살아있는 동안에는 엑셀 파싱과 외부 지오코딩 API 횟수를 극적으로 절감(초기 로딩 속도 1초 이내로 단축).
  - Supabase 데이터베이스와의 통신(`실태조사 완료여부`) 시 `try-catch` 블록을 구성해 연결 오류를 방어하고, UI 상에서는 끊김 없이 상태(`완료/대기`)가 반영되도록 비동기 처리 구조화.
